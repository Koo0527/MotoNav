# MotoNav 读秒版 8.3.26-single.29

这是当前读秒版的完整自主源码与构建工具，和 [普通版 8.3.26](../standard/README.md) 分开维护。手机只安装一个最终 APK，使用现有的单引擎导航流程。

**红绿灯读秒属于实验功能，不保证一直有效，也不保证每个路口、每个方向都有数据。** 上游服务、版本、权限、账号、定位、路口覆盖、网络与系统后台限制变化都可能使其缺失或失效。缺数据时不补造读秒；必须以现场交通信号为准。

## 这一版包含什么

- 驾车选路及 60／100／120 km/h 模拟速度、网页摩托车多方案规划、自行车与分享入口。
- 摩托车／驾车最多三个手动途经点，支持搜索加油站、排序、替换与删除；网页摩托车历史保存途经点顺序，支持收藏与历史重选。
- 导航中返回设置与恢复、锁屏恢复保护、蓝牙连接及地图更新处理、主页时间同步。
- 最新网页锚点修正，避免自动途经点紧靠转弯时干扰路口方向核对；保留方向、位置和数据时效检查。
- 小屏右侧竖排路口图标和秒数；缺少右转数据时用灰色图标／灰色实心圆表示，不把它当成已确认的绿灯。

## 构建完整 APK（Windows）

准备 Python 3、JDK 17、Android SDK 35 / build-tools 35.0.0、Gradle 8.10.2、apktool 2.12.1 和 Zig 0.13.0。Zig 用于从 `native-route/route_bridge.cpp` 编译本项目的路径读取库，仓库不提交本地生成的库和输入 APK。

根目录执行 `一键打包-读秒版.bat`，依提示提供本机工具路径；也可在本目录运行：

```powershell
python build-countdown.py --provider 'D:\Inputs\provider.apk' --apktool 'D:\Tools\apktool.jar' --gradle 'D:\Tools\gradle-8.10.2\bin\gradle.bat' --sdk 'D:\Android\Sdk' --java-home 'D:\Tools\jdk-17' --zig 'D:\Tools\zig-0.13.0\zig.exe'
```

依赖已经缓存时可加 `--offline`。脚本校验输入、应用增量、构建路径读取库、编译自主源码、检查资源与重复类，并用本机新生成的开发签名签署最终包。

成品是 **`output/MotoNav-8.3.26-single.29-countdown.apk`**。`app/build/outputs/` 中的 Gradle APK 只是中间文件，不能当完整读秒版安装。Android Studio 可以打开本目录编辑和编译自主源码；完整包仍由上面的入口生成。

最终包名固定为 **`com.autonavi.amapauto`**，实际证书的十六进制 SHA1 会打印并保存到 `output/Application-info.txt`；用这两项申请自己的高德 Android Key。最终包系统版本字段保留兼容组件要求，MotoNav 内显示 `8.3.26-single.29`。私下备份并沿用 `.local/debug.keystore`，不要上传或群发。已安装同包名但不同签名的软件不能直接覆盖，先自行备份数据再决定安装方式。

`inputs/`、`car-code/`、`car-resources/`、`moto-code/`、`framework/`、`.local/`、`output/` 都是本机构建产物，已经忽略，不属于公开源码。构建过程中不安装手机、不发布仓库。

## 安装后首次使用

先按提示允许附近设备／蓝牙、定位及必要通知权限，并完成额外数据组件的首次授权与初始化；这是本人需要阅读确认的步骤，编译工具不会替你接受条款。随后在 MotoNav 连接圆屏，在“圆屏显示”中检查读秒开关。

如果地图正常而读秒没有数据，先核对初始化是否完成、定位是否新鲜、后台限制和路口覆盖。普通室内模拟不保证产生真实灯秒数；维护者的虚拟 GPS 测试也不等于所有用户在任意地点点模拟都能收到数据。
