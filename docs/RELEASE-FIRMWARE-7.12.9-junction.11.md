# 1.75 通用固件源码 7.12.9-junction.11

适用 Waveshare ESP32-S3-Touch-AMOLED-1.75（466×466），禁止刷入 1.85B 或 M5Stack StopWatch。Android 原版、融合版和 iOS 沿用现有导航协议；只有融合版有上游数据时发送实验灯包。iOS 不提供读秒。

本版整理主程序、图标、绘图和通信；保留精确计算缓存和绘图优化，车道提醒与转弯倒计时同步；右侧竖排多灯、过期清理、灰色未知右转，以及网页导航转弯环按距离更新间隔连续填充。保留电池五分钟无导航关机和插电不自动关机。

**公开版使用通用 MotoNav／品牌开机动画，不包含维护者个人 Rebel 500 图片及绘制分支。** 默认品牌为 MotoNav；App 仍可选已有品牌，保存的品牌编号继续有效。

Windows：安装 Arduino CLI、Espressif ESP32 Core 3.3.10 后，在仓库根目录执行：

```powershell
.\firmware\build.ps1 -Board 175
```

Mac／Linux：`python3 firmware/build.py`。生成在 `firmware/dist/175/panel0`，升级程序分区为 `app_0x10000.bin`；首次完整镜像为 `full_0x0.bin`，需先核对板型与分区，完整刷写可能影响设置。此轮不新增或覆盖历史 Release／一键烧录 ZIP，旧 Release 不能视为本版本。

先前个人启动图版本已在实物虚拟导航确认“圆环连续了，其他正常”；通用启动图公共副本另行编译，尚未重刷硬件。其构建结果见 [验证说明](VERIFY-2026-10-25.md)。真实道路与长时间后台运行仍待验证，不承诺固定帧率、读秒覆盖或无任何闪烁。

1.85B 本轮仍为 7.12.3-185B，未声称同步新灯卡片与渲染改动。
