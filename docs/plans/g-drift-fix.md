# G 值漂移与校准修复

目标：可信停车后恢复零点，运动和未知时保留真实持续加速度，补齐采样中断恢复；G 页移除分页点。

## 已确认约束

- 停车 / 运动 / 未知三态来自独立真实定位，不能使用模拟导航速度。
- CAP,GMOT,1；#GM,0/1/2 每秒更新，固件有效期 3 秒，认证连接会话隔离。
- 原始定位年龄 <=2s、水平精度 <=20m、速度精度 <=0.5m/s；速度 <=0.3m/s 停车，>=1m/s 运动，其余未知。
- 保留停车入页约 3 秒自动安装校准；离线未知仅在入页校准时假定用户停车，运行时不强制归零。
- 保留 NVS 安装结构、A7 帧、历史记录、物理方向、积分时基和配对数据。

## 实施与验证

1. 先复现无 tilt 标记的重力恢复失败，以及未知运动时小加速度被缓慢消除；改为可信停车独占重力和运行偏置学习。
2. 固件运动状态认证、到期、会话重置；可靠运动禁止所有停车初始化，未知需重新停车入页恢复。
3. 手机原始定位质量判断及每秒上报；生命周期失效后报告未知；注册 CI 回归。
4. 采样故障中断稳定窗口并标为无效；添加批次与重置诊断；移除 G 页分页点。
5. 数学/运行/蓝牙/记录/图表回归，构建匹配 iOS 和 1.75C 固件。
6. 固定支架水平、45°、近竖直各预热 1 分钟并观测 10 分钟；再做地图/音乐/G 记录并行 60 分钟。真实运动依据不足和用户未完成设置时必须记为未验收。

不做道路精度认证、温度补偿曲线和六面标定。无真实停车依据时六轴仍可漂移。
