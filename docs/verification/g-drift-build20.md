# G 值漂移修复：Build20 / 175c.5

## 已实现

- 使用真实手机定位生成停车 / 运动 / 未知状态，与模拟导航车速分离；能力协商后每秒上报，三秒过期。
- 定位权限、系统开关、精度、年龄、速度和软件模拟来源均校验；后台、断连及重新连接不复用旧停车状态，蓝牙实际写入前重新检查。
- 固件 RX 入队时捕获认证、连接代次和接收时刻；出队不延长停车状态寿命，不信任旧会话和认证前的消息。
- 可信停车连续稳定约三秒后恢复重力和陀螺偏置；未知和运动只跟踪姿态，不把真实持续加速度吞进重力。
- 保留停车入页自动安装校准；可靠运动暂停校准，运动状态丢失不能偷偷重启，需可靠停车或重新入页。
- FIFO / 时间 / 饱和等异常中断稳定窗口及有效输出；无效姿态不能在运动中重新初始化。
- 保留 NVS 安装参数、A7 数据帧、历史格式、物理方向和积分时基；G 页分页点已移除。

- 运动消息 TTL、续期、认证、连接代次、排队延时、计数回绕及 Moving→Unknown 校准阻断通过。
- Swift 运动状态和真实定时器取消、定位权限适配、十八项蓝牙能力、72,000 样本记录、图表、ios-fixes 与 tunnel-settings 回归通过。
