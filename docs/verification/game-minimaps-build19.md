# 三款游戏小地图：Build19 / 175c.4

## 实现与兼容

- 主题编号 1/2/3 保持不变，主题 3 更名“赛博朋克”。保留其余主题及纸地图夜间别名外观。
- VC 使用浅灰白地面、黑路、蓝水、绿地、粉紫路线／外圈；GTA5 使用炭灰街区、
  浅灰道路和紫色路线；赛博朋克使用近黑底、暗青道路、灰紫建筑轮廓和浅黄点线。
- 固件纯头文件 `GameMapStyle.h` 是主题配色和标记几何来源，昼夜预览复用同一来源。
- 三种主题共享原建筑开关，保留有效缓存和既有数据协议。底图先行，建筑随后补充；
  三种主题均校验空白底图，并保持地图块重叠处建筑连续与道路／水域优先。
- 点线每 14 米布点，使用路线起点累计距离锚定、视口裁剪和 double 循环计数。
  支持走过路线变暗／擦除、急弯与路况点段着色。累计距离缓冲分配失败时保留实线路线。
- VC 进度环保持粉紫，赛博朋克进度环为青色；警示、转弯、行程、基环按优先级绘制，
  缓存同时校验主题、昼夜和实际颜色。GTA5 航点最终按用户更正为紫色四向形、
  黑色描边、透明中心；中心像素完全不写入，实际底图可透出。边缘方向标亦无白边。
- 道路高低层深浅暂不实现：现有截图分类只有单一道路材质；已接入导航线路段类型
  不能可靠标注周边全部道路的上下层。用户明确允许本轮跳过。

## 验证

- 22 套 C++ 与 C 闲置关机回归通过 ASAN/UBSAN。新增测试覆盖放置避让、无可用位置、
  外圈优先级／缓存、四向航点非均匀底图透明孔、点位相位和极长路线有限采样。
- 实际固件解码器测试覆盖主题 1/2/3 的连续建筑保留、开关清除、道路与水域优先。
  三份 iOS 接收器夹具与固件源码逐字节一致。
- iOS search/rides/navigation UI/position/BLE 五组、设备设置与 12 主题重启、
  72,000 样本 G 记录回归通过。四种底图隔离、688 项地图处理、地图交付测试通过。
- Swift 初次独立测试遇到 `/tmp` 与 `/private/tmp` 同一缓存的模块重复加载崩溃，
  使用新建的唯一规范路径缓存后通过；无需修改产品代码。
- 签名 Release Build19 已构建、覆盖安装并启动；175c.4 构建通过。
  应用程序 1,343,371 字节，静态 RAM 117,060 字节，比 175c.3 静态 RAM 增加 16 字节。

## 另行记录：模拟导航时的 G 估计

附带诊断在 GTA5 采样中记录到加速度读数约 `0.05/0.003/1.006g`，但估计重力
逐步偏向 `0.415/0.307/0.857`，输出偏至约 `0.334/-0.348g`。随后姿态重置后
输出回到接近零。此现象说明模拟导航期间仍有 G 估计累积漂移，需单独定位，
不能把本轮地图帧率或先前静置校准通过当作 G 长时精度通过。本轮没有修改 G 算法。
