# 二维地图优化：Build23 / 175c.7

## 交付内容

- 手机制图仅三游戏主题启用新处理：保留原始道路、水域和绿地；安全的局部补点/加粗不会合并原本分离的道路或填道路孔洞。其他主题沿用旧算法。
- 4m建筑掩码清除有稳定支撑的单格突刺；保留连接、庭院和外圈边界；合成时统一填充/轮廓并让道路、水域优先。
- 新底图materials-v2、建筑fast4m-v2独立命名。有效v1分片校验后本地转换，原文件保留；旧完整包继续回退。新采集不把旧版底图冒充新质量；complete旧缓存路径不触发新底图保存回调。部分/完整语义与进度不退保持。
- 屏外航点复用主题图形：VC方形、GTA5空心四向紫标且仅黑边、赛博朋克六边形，保留北标/HUD避让。
- 固件实现纯/混合16²块元数据及RGB565局部插值，与增量解码、建筑继承、原子提交/取消绑定。低内存、卫星、其它主题及VCE沿用原采样。
- **正式固件AA关闭**：没有通过设备开销门槛；代码保留供后续优化，不把审阅图当作已默认启用效果。
- 未改蓝牙线格式/材质编号，未清空离线包、历史、配对或安装校准；没有提交、推送或发布Release。

- 新缓存迁移测试先红后绿，覆盖v1校验转换、保留边界、重复读取、损坏v2回退、旧完整包优先和原文件不删除。
- 旧完整包不触发新底图回调的回归先红后绿；SDK采集与离线生产调度通过。
- 既有iOS修复/统一规划、G记录/定位/图表、隧道/设置、688项地图、样式、交付、碎片/确认恢复及导出回归通过。
