# 新区域建筑首批优化：Build21

## 实现与范围

四片近景取图保留；道路优先，视野重叠/朝向排序，第一片有效建筑立即发布，余片合并为完整包。
每对开关建筑截图串行完成，片间允许道路或新显示块首批建筑抢先；没有增加截图次数。
掩码按4m简化，过滤不足64m²的小片；底图保持2m，道路/水域优先，建筑填充与边线保持。

checkedMask与是否有屋顶分开：空片可以完成、失败/取消不完成；部分缓存可续接。
三游戏主题共享新版分片和地图包，已有旧完整包继续读取，其他主题隔离。
切换兼容主题保留采集任务，其他失效任务取消。共享包带覆盖元数据和校验，不能进入旧完整包命名空间。
传输中的首批不因尾批就绪被取消；原始尾批等待ACK后重新预算。预算不够继续保留已确认道路。

本轮使用Build21（Build20已用于G修复），无固件改动，保持175c.4协议兼容及当前175c.5功能。
没有删除用户离线包，也没有重置配对、G记录或设置。
