# MotoNav iOS 0.15.1 · 圆屏大字时钟校时

在 0.15.0 源码基础上新增一项功能：**把手机时间通过蓝牙同步给圆屏**，供骑行模式待机画面的大字时钟（HH:mm + 日期）显示。

## 新增

| 功能 | 说明 |
| --- | --- |
| 蓝牙校时（#TIME） | 新增 `PhoneClockWire.swift`：把手机当前 UTC 秒 + 本机时区偏移编码为 `#TIME,<秒>,<偏移>` 文本协议，与安卓 8.3.26 的 `PhoneClockWire` 完全一致 |
| 发送时机 | 与安卓同节奏：连接就绪后立即发送一次；此后每 2 秒心跳里检查，同一时区下最多 60 秒重发一次，修正手表走时漂移 |
| 不缓存重放 | 校时命令不进入状态缓存，重连时总是使用当前墙上时间（沿用安卓行为） |
| 圆屏侧 | 固件 `HomeClock` 收到后驱动待机页大字时钟；无此功能前 iPhone 用户只能看到灰色的 `--:--` |

## 说明

- 本版需配合圆屏固件使用：任何含 `HomeClock.h` 的固件（上游 7.12.10+，含 143C 适配版 v7.16+）均可接收。
- IPA 为未签名包，安装方式与 0.15.0 相同（见 `docs/INSTALL-IOS.md`）。
- 除校时外无其他改动；0.15.0 的全部功能保持不变。
